# Token2API 品牌资料

Token2API 使用独立的相向折带标志，表达连接与交换。首页、控制台和钱包入口统一使用该标志。

- `public/token2api-mark.svg`：透明矢量品牌标志。
- `public/icon.svg`：浏览器矢量图标。
- 采用青绿色操作主色、深蓝灰导航与中性浅色背景。各链使用独立色彩作区分，不将单一链的配色作为平台身份；不引入外部字体文件。
- 首页说明多链结算和 Native、USDT、USDC 资产类别。具体可用网络和资产以当前部署配置为准。

## 页面与描述

- 产品定位：面向 AI 资源交易的多链结算平台。首页先说明网络和资产，再说明预算、调用、结算与退款。
- 链目录：从应用支持的链配置生成，同时显示原生代币。USDT、USDC 按具体链和代币合约开通，不标记为所有链均已上线。
- 控制台：突出当前市场的网络、结算资产与手续费币种；创建预算前再次确认这些信息。
- 页面用“当前市场”说明用户正在使用的链和资产。部署隔离、代币精度等技术细节放在运维和 API 文档。
- 操作称谓统一为“我的资源”“预算会话”“账单与结算”“可提现余额”。退款释放到可提现余额后，仍需原钱包提取。

## 多链视觉

首屏采用网络节点连接到预算结算中心的示意图，节点来自应用支持的链目录，并展示各链原生代币。节点颜色仅用于区分网络，不表示运行状态或已完成实际部署。原生代币、USDT、USDC 统一作为结算资产类别展示。

首页、控制台、钱包弹窗、SVG 标志与 ICO 使用同一套青绿和蓝灰色系。Token2API 相向折带标志保留，首屏不再使用单链代币、轨道图或立体币图形。

页面使用浅色背景、深色多链示意面板与青绿色操作按钮。网络卡片采用相同尺寸、圆角和图形标识，各链平等展示。链标识为页面自绘的符号或缩写，不表示网络运行状态。控制台沿用相同色彩与留白，未开通市场使用独立空状态，不展示模拟资金。

控制台的概览、资源市场、我的资源、调用实验室、账单与结算、API 密钥共用同一套导航、市场信息条、卡片、表单和弹窗样式。市场信息条显示当前网络、结算资产和手续费币种；侧栏的支持网络目录不表示可切换账本。开发预览可查看模拟会话、账单和密钥，后端操作仍由预览传输层阻止。
