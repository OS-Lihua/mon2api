# 接入管理后台

控制台右上角的“管理后台”进入 `/admin`。使用当前托管合约的 `owner()` 钱包连接并签名登录。服务端在每次后台读取和修改前重新核对链上管理员；普通商家、调用者和演示登录均没有管理权限。链上身份读取失败时拒绝后台操作。浏览器不需要管理员私钥，沿用现有钱包签名登录。

## 网关和代理白名单

1. 点击“新增地址”，选择“网关 API 地址”，填写名称、完整 `base_url` 和备注。远程网关须使用 HTTPS；HTTP 仅允许回环地址。
2. 需要代理时，另添加“网络代理地址”。支持 HTTP/HTTPS 代理，只填写协议、主机和端口，不含路径或认证信息。
   带认证的远程代理必须使用 HTTPS；只有 `localhost`、`127.0.0.1`、`[::1]` 回环代理允许 HTTP 认证。此规则也在运行时检查，已有不安全配置会停止调用，须改用 HTTPS 后重新接入。
3. 商家使用获准的网关地址和调用 Key 接入资源，可选填写获准的代理地址及代理用户名、密码。模型发现和调用使用同一代理。
4. 使用名称、地址、备注搜索，按地址类型和启用状态筛选白名单。列表按最近更新时间排序，每页 10 条。点击“关联资源”后，焦点移到资源列表；资源每页最多 25 条，支持上一页和下一页，也可回到全部资源。后台不返回上游 Key 或代理凭证。

网关规范化后按完整基础地址精确匹配，包括 API 路径；根地址自动补 `/v1`，忽略尾部斜杠及 URL 默认端口。例如批准 `https://gateway.example/v1` 不会放行 `/other`、其他端口或子域名。不支持域名后缀通配。代理按规范化后的协议、主机和端口精确匹配。所有未获准的网关、代理默认拒绝访问，使用代理不会绕过网关白名单。

编辑说明使用弹窗，地址类型和地址只读；保存失败时保留输入，提交时禁止重复操作。加载失败与空数据分别显示，并提供重试。

重复保存相同类型和地址会更新名称、备注，保留原启用状态。地址不可原地替换；要变更地址，添加新记录并停用旧记录。记录保留创建时间、修改时间和最后操作钱包。

## 停用和恢复

点击“停用”后先核对确认弹窗中的地址、关联资源数和影响范围。确认后，会在同一数据库事务中停止关联直连资源的新接单。模型发现、资源接入、重新上架、新建消费会话以及每次调用都检查白名单。已经受理的请求继续执行；结算、关闭、退款和提现不依赖白名单。

重新启用地址不会自动上架资源。商家确认服务恢复后，再从“我的资源”重新上架；使用的网关和代理都须处于启用状态。

## 本机连接器边界

本机连接器的上游地址和密钥保留在商家机器上。后台会将这类资源标为“本机连接器 · 上游未核验”，不把商家上报结果视为已通过直连地址核验。平台直连的白名单和代理配置不控制商家本机的出站网络。

代理必须能从实际发送请求的机器访问。在平台直连模式填写 `127.0.0.1` 指的是平台服务器，不是商家电脑。禁止跟随上游重定向；代理连接失败不会改为直连，也不会自动重发推理请求。代理认证信息加密保存，并且只发送给指定代理。

## 升级

部署前运行 `pnpm db:migrate`。白名单改由数据库和后台管理，不再读取 `UPSTREAM_ALLOWED_ORIGINS`。迁移不会自动批准旧网关；现有平台直连资源会暂停。管理员须审核并添加完整网关地址，之后由商家重新上架。现有消费资金、计价单位、账单、结算和退款记录保持不变。
