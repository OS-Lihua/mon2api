# Token2API 开发任务与验收

状态以完成验证为准。核心集成已通过本地浏览器与HTTP smoke；真实钱包扩展、真实上游和测试网验收另列。

## 已交付的独立模块

- [x] 预算托管合约：`DemoUSD`、`UsageEscrow`；基于 OpenZeppelin 实现锁预算、累计结算、分账、关闭和提现。验收：本地 EVM 合约测试覆盖权限、nonce、防超支、手续费舍入和退出窗口。
- [x] 上游网关独立适配器：复用官方 OpenAI SDK，文本流式调用、会话标识、上游 ID、取消与错误脱敏；不自动重试。验收：`src/server/services/pool-engine.test.ts` 通过。
- [x] 明确标记的 demo engine：无真实模型请求，输出和用量来源可区分。验收：相同输入重复得到相同结果，测试确认不访问上游。
- [x] 号池接入文档：明确提供者归属、凭证权限、精确 origin 清单、参考版本和许可边界。验收：[POOL.md](./POOL.md)。

## 需要凭证或外部环境验证

- [ ] **真实上游调用**。依赖：获授权部署、真实协议密钥、可用账号、允许的 origin、准确模型名。验收：一次真实流式调用包含最终 usage 和可追溯的上游 ID；模拟响应不能替代此验收。
- [ ] **真实钱包操作**。依赖：浏览器钱包和本地链或测试网配置。验收：签名登录、授权 dUSD、锁预算、提现及拒绝错误网络；点击模拟按钮不能替代钱包签名验证。
- [ ] 各支持链、各稳定币版本的真实钱包和网关资金闭环验收。
- [ ] **部署后上游隔离检查**。依赖：提供者自己的上游执行环境。验收：账号归属、凭证存储、进程/文件/网络权限由提供者验证；Token2API HTTP 单元测试不能证明 VM 隔离或不会封号。

这些任务只需要在对应部署时提供凭证，不应把真实账号或密钥写入代码仓库。

- [ ] 官方参考价与可信型号：后端维护人工复核的厂商型号、标准计费档、币种、输入/输出价、来源和日期，经服务契约供页面展示；未核实卖方型号及币种时不能返回可比差额。前端只在身份和计费条件均已核验后显示差额，模拟资源不显示虚构折扣。后端已接收任务，本轮先完成合约开通和全仓验证。
- [ ] 一次真实供需交易：找有使用和转售权限的外部卖方，核对网关 origin、模型能力、最终 usage 和上游请求 ID；陌生买方完成一笔目标工具中的调用、账单、提供者收入与消费者退款。记录费用、异常人工核对和端到端时延。
- [ ] Magpie / CC Switch 买方导入：先选一个客户端与协议，验证每个逻辑请求可生成重试稳定的 `Idempotency-Key`，并测试流式、工具调用及最终 usage；随后提供只在私密页面生成的导入入口，以目标工具实际调用和对应账单验收。单纯导入配置不算完成。

## 当前验证记录

本地浏览器已完成使用者锁预算、调用、Key创建/撤销、关闭退款，以及提供者上下架和提现；HTTP smoke验证官方SDK普通/流式调用、重复幂等键不增加账单、重复结算不增加金额、关闭后Key失效。自动测试覆盖合约资金边界、输入约束、计费整数、上游异常与API安全工具。真实浏览器钱包扩展和外部服务没有用演示身份替代验收。

恢复故障注入已通过真实本地PostgreSQL与EVM验证：模拟链上成功而数据库确认丢失，重试恢复原交易，nonce和消费不增加，账本仅一条结算记录。显式运行 `TOKEN2API_RECOVERY_TEST=true pnpm test:recovery`；只允许本地演示环境。


## 多链结算

- 保留 `UsageEscrow`、`DemoUSD` 和原有事件恢复逻辑以维护历史部署。迁移只增加 ChainBinding.asset，既有绑定仍为 dUSD，禁止重解释历史资金。新部署必须隔离数据库和数据目录。
- 当前仅兼容文本 Chat Completions，调用方仍须为每个逻辑请求生成 Idempotency-Key。测试网资金不代表主网支付能力。
