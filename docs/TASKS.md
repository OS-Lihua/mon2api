# mon2api 开发任务与验收

状态以完成验证为准。核心集成已通过本地浏览器与HTTP smoke；真实钱包扩展、真实上游和测试网验收另列。

## 已交付的独立模块

- [x] 预算托管合约：`DemoUSD`、`UsageEscrow`；基于 OpenZeppelin 实现锁预算、累计结算、分账、关闭和提现。验收：本地 EVM 合约测试覆盖权限、nonce、防超支、手续费舍入和退出窗口。
- [x] 上游网关独立适配器：复用官方 OpenAI SDK，文本流式调用、会话标识、上游 ID、取消与错误脱敏；不自动重试。验收：`src/server/services/pool-engine.test.ts` 通过。
- [x] 明确标记的 demo engine：无真实模型请求，输出和用量来源可区分。验收：相同输入重复得到相同结果，测试确认不访问上游。
- [x] 号池接入文档：明确提供者归属、凭证权限、精确 origin 清单、参考版本和许可边界。验收：[POOL.md](./POOL.md)。

## 需要凭证或外部环境验证

- [ ] **真实上游调用**。依赖：获授权部署、真实协议密钥、可用账号、允许的 origin、准确模型名。验收：一次真实流式调用包含最终 usage 和可追溯的上游 ID；模拟响应不能替代此验收。
- [ ] **真实钱包操作**。依赖：浏览器钱包和本地链或测试网配置。验收：签名登录、授权 dUSD、锁预算、提现及拒绝错误网络；点击模拟按钮不能替代钱包签名验证。
- [ ] **Monad 测试网部署**。依赖：RPC、测试 MON、部署者与 meter 凭证。验收：保存部署地址、chain ID 和交易；真实钱包调用已部署合约，核对提供者收入与消费者退款。
- [ ] **部署后上游隔离检查**。依赖：提供者自己的上游执行环境。验收：账号归属、凭证存储、进程/文件/网络权限由提供者验证；mon2api HTTP 单元测试不能证明 VM 隔离或不会封号。

这些任务只需要在对应部署时提供凭证，不应把真实账号或密钥写入代码仓库。

## 当前验证记录

本地浏览器已完成使用者锁预算、调用、Key创建/撤销、关闭退款，以及提供者上下架和提现；HTTP smoke验证官方SDK普通/流式调用、重复幂等键不增加账单、重复结算不增加金额、关闭后Key失效。自动测试覆盖合约资金边界、输入约束、计费整数、上游异常与API安全工具。真实浏览器钱包扩展和外部服务没有用演示身份替代验收。

恢复故障注入已通过真实本地PostgreSQL与EVM验证：模拟链上成功而数据库确认丢失，重试恢复原交易，nonce和消费不增加，账本仅一条结算记录。显式运行 `MON2API_RECOVERY_TEST=true pnpm test:recovery`；只允许本地演示环境。
