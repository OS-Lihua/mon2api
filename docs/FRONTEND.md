# 前端界面与交互

Token2API 使用 Next.js、React、TypeScript、Tailwind CSS、Lucide 与现有 Radix 下拉组件。Web 内部操作沿用 tRPC 和 TanStack Query。没有新增依赖。模型 Key 与预付账户复用共享服务，钱包签名与权限检查保持不变；资金规则见 [MODEL_ROUTING.md](./MODEL_ROUTING.md)。

## 视觉与组件

全局设计变量定义在 `src/styles/globals.css`。`--ink`、`--muted`、`--line`、`--frost` 定义内容与边界；`--accent` 和 `--accent-hover` 定义主要操作；`--positive`、`--warning`、`--negative` 及对应浅色背景定义语义状态。控件、面板和弹窗使用统一圆角变量。首页复用这些颜色变量，保留官网的版式和网络说明。品牌标志继续使用现有资产。

- `console/ui.tsx`：状态、面板、空数据、加载、查询错误、可滚动表格和原生 dialog。
- `console/collection.tsx`：共用搜索、筛选、分页与分页状态。筛选或排序变化时返回第一页；记录减少时限制到有效页。
- `console-select.tsx`：沿用 Radix 的方向键、文字定位、Escape 与弹窗内的浮层容器。
- `shared/money.ts`：所有报价、费用、预算和链上余额使用共享金额工具，页面不重新计算计费。

## 用户路径

控制台使用 Next.js App Router 的文件路由。概览为 `/console`，资源市场为 `/console/market`，我的资源为 `/console/pool`，调用实验室为 `/console/lab`，账单为 `/console/billing`，API 密钥为 `/console/keys`；管理员进入 `/admin`。每个地址可直接访问、刷新或在新标签页打开，浏览器前进和后退同步更新内容与导航。未知地址返回 404。首页的调用者和商家入口分别进入市场与我的资源页面。

`console/layout.tsx` 保留钱包 Provider 与控制台的共享操作状态，子路由选择对应页面并提供独立标题。页内导航沿用 Next.js Link 和 Router，不使用手写 history 切换。切换控制台页面时保留调用草稿、当前 Key 和模型及本次返回的密钥；钱包身份变化时仍清除敏感状态。导航后聚焦当前页面标题并关闭手机菜单。已有 `/console#market` 等已知分区链接会替换为对应的新地址。

模型市场每页 9 条，支持模型名称和 ID 搜索、可路由状态筛选与输入/输出价格排序，显示平台统一报价（当前资产 / 百万 Token）。从模型行创建 Key 会预选该模型。`model-picker.tsx` 复用复选框、搜索、状态和价格组件，明确授权 1–100 个模型；创建与编辑共用，新增平台模型不会自动授权。`prepaid-account.tsx` 在密钥页和账单页显示同一钱包的可用余额、准备预留、用量预留、待结算与待退回金额。余额查询按钱包地址缓存；切换身份清除敏感状态。充值和提取表单保留失败输入，钱包在每一步签名前核实身份、网络、目标、方法与金额。

预算会话每页 5 条；请求、结算与密钥每页 8 条。会话、请求与结算来自最多 100、200、100 条相关记录；前端筛选和分页不查询更早的历史。密钥按当前返回的元数据分页。撤销密钥前确认影响，完整密钥仍仅返回和显示一次。

商家页展示资源数量、当前记录中的商家关联调用与链上可提现余额。余额可能同时包含收入和退款，不能作为独立商家净收入。后台模型每页 8 条，支持搜索、统一报价编辑、资源映射和优先级设置；候选资源每页 25 条。白名单每页 10 条，按更新时间排序；关联资源沿用服务端 cursor，每页最多 25 条，维护前一页的 cursor。停用地址前展示影响范围。

## 状态与资金

加载、空数据、查询失败、提交中和成功反馈使用不同展示。后台查询失败时不显示为空列表。刷新失败时控制台明确提示当前数据来自上次读取。提交时禁用相关操作，并使用同步锁防止重复触发。

REVIEW、PENDING_USAGE、执行中或缺少用量的非失败请求，费用显示为“待核对”。即使存在陈旧的已结算标记，也优先展示用量未确认状态。预算预留单独显示，不作为可用余额或最终费用。明确失败并释放预留的请求可显示已确认的零费用。可提现余额与钱包余额分开展示；申请退款不等于钱包已到账。

调用实验室选择模型 Key 与该 Key 已授权的模型，通过现有非流式 tRPC 调用。模型或 Key 变化时重置对话上下文，跨页面保留输入草稿。请求中显示等待完整响应，成功后展示文本、Token 与当前资产单位的费用；不提供流式输出或停止控制。支持 Ctrl / ⌘ + Enter；中文输入法组合输入时不触发。失败保留输入，引导先查看账单，避免重复调用。

## 键盘与手机

原生 dialog 结合显式 Tab 双向循环管理焦点范围，打开时聚焦首个表单控件，Escape 关闭后恢复触发点。提交中禁止关闭和重复提交。弹窗内的下拉菜单先处理 Escape。手机导航锁定背景滚动并隔离主内容，关闭后恢复菜单按钮焦点；切回桌面时退出手机导航状态。宽表格保留可聚焦的滚动区域和滑动提示。所有主要表单、筛选与确认操作在手机上可用。

资金展示回归测试位于 `tests/console-billing.test.ts`，钱包切换的凭证隔离测试继续保留在 `tests/console-identity.test.ts`。`tests/console-admin.test.ts` 覆盖预览模式无钱包 Provider 时的后台渲染，确保不启动受保护查询或渲染钱包操作。界面预览仅在 development 下使用 `NEXT_PUBLIC_UI_PREVIEW=true`，不会执行后端写入。正式权限与链上交易需要在实际配置环境验证。

模型路由的服务回归位于 `src/server/services/model-routing.test.ts`；钱包交易篡改校验位于 `tests/prepaid-wallet.test.ts`。`pnpm test:native`、`pnpm test:stable` 及后者的 `--18-decimals` 参数在隔离数据库 schema 和回环 EVM 上验证原有会话与新的模型路由、统一报价、预付余额、分账恢复及 REVIEW；不会连接生产签名器或真实资金。
